# California Roadtrip Companion

A mobile-first, single-page travel guide for a 12-day California family roadtrip (Patel × Panchal families, May 30 – June 10, 2026).

Single `index.html` — no build step, no frameworks. Works on GitHub Pages.

## View it

Live URL: `https://krupesh9.github.io/Code/ca-roadtrip/`

Direct link — not listed on the arcade home page.

## Screens

- **Today** — countdown / today banner / pre-trip checklist
- **Days** — swipeable carousel of all 12 days
- **Stays** — 6 accommodations with copy/maps buttons
- **Logistics** — flights + rental car confirmations
- **Eats** — searchable list of 15 Indian / veg-friendly restaurants

## Tech

- Vanilla HTML/CSS/JS in one file
- Inter + Fraunces from Google Fonts
- Wikimedia Commons photos with `onerror` gradient fallback
- PWA meta tags (add to home screen)
- `noindex` so search engines don't surface it
