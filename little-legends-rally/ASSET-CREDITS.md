# NIGHTSHIFT — asset credits

This is an independent, noncommercial browser game. Vehicle names identify the represented cars; manufacturers do not endorse this project. Performance numbers are game balance values.

All models are modified: geometry consolidated and simplified, interior components reduced, textures resized, materials and controls adapted. Model derivatives retain their original licenses. Code is separate from model assets.
